# CV Strategy Notes — V1.3

## What the four additional CVs changed

The older Mechanical and Wind CVs contain important evidence that is either compressed or absent in the compact Fraunhofer version. V1.3 therefore does not treat one CV as the canonical wording for every job.

### Mechanical versions are the stronger source for

- end-to-end product/machinery development;
- requirements, concepts, detailed design and design for manufacturing;
- SAP-based product/engineering data;
- component and vibration-motor selection;
- manufacturing/assembly/shop-floor coordination;
- the fuller vibrating-screen development story;
- the hand-prosthesis / additive-manufacturing project.

### Wind versions are the stronger source for

- current rotor-as-sensor Master's thesis;
- OpenFAST case generation and workflow automation;
- signal processing and linear vs neural-network estimator work;
- fuller 20 MW offshore load-analysis wording;
- windPRO/QGIS planning and environmental assessment;
- current expected graduation information.

### Fraunhofer version is useful because

It is more compact and targeted. Its strength is concision, not breadth. V1.3 keeps it as a specialist source for certain English wind/thesis applications, but not as the universal master CV.

## Wording problem in the old four-CV approach

The four CVs are not bad, but using them as fixed final documents creates two problems:

1. **They are dense.** Each tries to explain a large portion of the candidate's history, so a specific employer may have to search for the most relevant evidence.
2. **The split is too binary.** Real jobs do not fall neatly into only `Mechanical` or `Wind`. CAE, simulation, validation, technical application, R&D, project engineering, renewable energy, systems and other roles can sit between them.

V1.3 solves this by using the files as an evidence bank, then producing a shorter job-specific version.

## Dynamic CV policy

For each job:

- choose a base in the correct language;
- keep all professional roles and education truthful;
- select the strongest 2–3 bullets per professional role;
- include current thesis/wind projects only when they strengthen the application;
- include mechanical projects only when they strengthen the application;
- use transferable capability without changing the historical job title into a role that was never held;
- keep metrics only when explicitly supported;
- aim for <= 2 pages;
- keep German at B1/learning;
- keep personal details as placeholders.

## Examples of legitimate broader positioning

These are **search directions**, not automatic claims of qualification:

- CAE / FEM / FEA Engineer
- Berechnungsingenieur
- Structural Dynamics / Vibration Engineer
- Simulation Engineer
- Mechanical / Product Development Engineer
- R&D Engineer
- Test / Validation / Verification Engineer
- Manufacturing / Industrialization / Project Engineer
- Renewable Energy / Wind Project Engineer
- Wind-Farm Planning / Site-Assessment Engineer
- CAE Application Engineer / Technical Consultant
- Engineering Automation / Computational Engineer
- Systems Development / Research Engineer
- selected Controls / Mechatronics / Robotics roles
- selected Reliability / Condition / Mechanical-Integrity roles

The agent's job is to find these opportunities and then distinguish `core`, `adjacent`, and `stretch` matches honestly.
